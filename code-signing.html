Code Signing Policy

Mount Sheet Sync · Русский

Status: MountSheetSync.exe is currently not signed. A code signing certificate costs money every year, and the free signing for open-source projects (SignPath Foundation) is meant for projects that are already widely used, so it is not available to Mount Sheet Sync yet.

Because of that, Windows SmartScreen may show “Windows protected your PC” when you start the program for the first time. Click “More info” → “Run anyway”. Download the program only from this website or from the project's GitHub releases — the code and the build are public, see below.

What would be signed

Only MountSheetSync.exe — the Windows program of Mount Sheet Sync, built from this repository. The World of Warcraft addon consists of plain Lua files and is not signed.

How releases are built

  • Every release is built by GitHub Actions from a tagged commit of the public repository (release workflow), with the C# compiler that ships with Windows. Nothing is built or signed on a personal computer.
  • The build contains only code from this repository; it has no third-party binaries.
  • If signing is added later, signing requests will be submitted by the release workflow and must be approved manually before anything is signed.

Team roles

  • Committers and reviewers: Zlodyaga
  • Approvers: Zlodyaga

All team members use multi-factor authentication for GitHub.

Privacy

The program sends data only to Google's servers, to your own Google account, when you sign in with Google to keep the mount spreadsheet. It does not transfer information to any other networked system. Details: privacy policy.

Политика подписи кода (по-русски)

Состояние: MountSheetSync.exe пока не подписан. Сертификат для подписи стоит денег каждый год, а бесплатная подпись для открытых проектов (SignPath Foundation) даётся уже широко известным проектам, поэтому Mount Sheet Sync её пока не получил.

Поэтому при первом запуске Windows может показать «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Скачивайте программу только с этого сайта или из выпусков на GitHub.

Выпуски собирает GitHub Actions из помеченного коммита открытого репозитория компилятором, встроенным в Windows, без сторонних двоичных файлов. Если подпись появится, подписываться будет только MountSheetSync.exe, и каждую подпись будет вручную одобрять Zlodyaga. Программа передаёт данные только серверам Google — в ваш аккаунт, для ведения таблицы, — и никуда больше: политика конфиденциальности.
