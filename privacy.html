Privacy Policy

Mount Sheet Sync · Русский

Effective date: 23 October 2026

Mount Sheet Sync consists of a World of Warcraft addon and a Windows program (“the program”). This policy explains what data the program accesses, how it is used, where it is stored and with whom it is shared. In short: your data stays on your computer and in your own Google Drive; the developer never receives it.

1. Google user data the program accesses

When you choose “Sign in with Google”, the program asks for these permissions:

  • https://www.googleapis.com/auth/drive.file — to create the mount spreadsheet in your Google Drive and to read and update only the spreadsheets the program created. The program cannot see, open or change any other file in your Google Drive.
  • openid and email — your Google account e-mail address, shown in the program's settings so that you know which account is signed in.

2. How the data is used

  • The spreadsheet is created and updated with game data from the addon: names and realms of your characters, the bosses they killed, and which mounts you have collected. The program reads the spreadsheet back to show what is left to do this week, in the tray menu and in the game.
  • The e-mail address is only displayed in the settings window and written to the program's local activity log.
  • Google user data is used only to provide these features to you. It is not used for advertising, it is not sold, and it is not used to develop, improve or train generalised artificial intelligence or machine learning models.

3. Where the data is stored

  • Your Google Drive: the spreadsheet itself. It belongs to you; you can rename, share or delete it like any other file.
  • Your computer, folder %APPDATA%\MountSheetSync: settings (game folder, which spreadsheet to use, language), the activity log, the list of records already sent, and the Google sign-in key (google-token.dat). The sign-in key is encrypted with Windows Data Protection (DPAPI) so that only your Windows user account on this computer can read it.
  • Your game folder: the addon's own files, including the “Remaining” list the program writes for the addon (Interface\AddOns\MountSheetSync\SheetData.lua).

There is no server operated by the developer. The program communicates only with Google's servers (accounts.google.com, oauth2.googleapis.com, sheets.googleapis.com, www.googleapis.com) over HTTPS. The program contains no analytics, telemetry or advertising.

4. Sharing

The developer does not receive, collect or share any of your data. Data leaves your computer only towards Google, to your own Google account, to provide the features described above. If you share the spreadsheet with someone in Google Drive, that is your choice and is governed by Google's terms.

5. Keeping and deleting data

  • “Sign out” in the program's settings deletes the sign-in key from your computer and asks Google to revoke the program's access.
  • You can also remove access at any time at myaccount.google.com/permissions.
  • Deleting the folder %APPDATA%\MountSheetSync removes all local data of the program. The spreadsheet in your Google Drive stays until you delete it.

6. Google API Services User Data Policy

Mount Sheet Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. The addon

The World of Warcraft addon does not use the network (WoW addons cannot). It stores its data only in the game's saved-variables file on your computer.

8. Changes and contact

Changes to this policy are published on this page, with a new effective date; the history is public in the site repository. Questions: GitHub Issues.

Политика конфиденциальности (по-русски)

Дата вступления в силу: 23 октября 2026 г. Mount Sheet Sync — аддон для World of Warcraft и программа для Windows. Коротко: ваши данные остаются на вашем компьютере и на вашем Google Диске, разработчик их не получает.

Какие данные Google использует программа

drive.file — создать таблицу маунтов на вашем Google Диске и работать только с таблицами, которые создала сама программа; остальные файлы Диска ей недоступны. openid и email — адрес почты аккаунта, чтобы показать в настройках, какой аккаунт подключён.

Как используются

В таблицу записываются данные из аддона: имена и серверы персонажей, убитые боссы, собранные маунты. Программа читает таблицу обратно, чтобы показать, что осталось на неделе. Адрес почты только показывается в настройках и пишется в журнал работы на вашем компьютере. Данные не используются для рекламы, не продаются и не используются для обучения моделей искусственного интеллекта.

Где хранятся

Таблица — на вашем Google Диске. На компьютере — папка %APPDATA%\MountSheetSync: настройки, журнал, список отправленного и ключ входа в Google, зашифрованный Windows (DPAPI) для вашей учётной записи. Список «Осталось» программа кладёт в папку аддона в игре. Серверов разработчика нет; программа обращается только к серверам Google по HTTPS. Аналитики, телеметрии и рекламы нет.

Передача

Разработчик ваши данные не получает и никому не передаёт.

Удаление

«Выйти» в настройках программы удаляет ключ входа и отзывает доступ у Google. Отозвать доступ можно и на myaccount.google.com/permissions. Удаление папки %APPDATA%\MountSheetSync стирает все данные программы на компьютере; таблица на Диске остаётся, пока вы её не удалите.

Использование и передача информации, полученной из API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use. Вопросы — GitHub Issues.
